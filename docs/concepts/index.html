Four new design directions for Livbetr

Version 1 kept the look of today’s site. These four are new directions, each a working prototype of the home page with real interactions. Open them, click around, then pick one, or a mix, and we’ll build the full site in it.

Direction A

Itemized

Honesty you can read. The price is a printed receipt with every line spelled out, and the fine print is set in big type instead of hidden.

Feels like
An editorial, typographic brand. Black on white, one highlighter color.
Type
Archivo, condensed for headlines; IBM Plex Mono for the receipt
Signature
Switch medication and the receipt reprints line by line
Effort
Low to medium. Few images needed.
Watch out
Austere for some visitors; needs strong copy to carry it
  • UI UX Pro Max: Swiss and editorial style, type search
  • Frontend Design: receipt concept
  • Make Interfaces Feel Better
  • Full build: UX Writing, A11y Enforcer
Open prototype

Direction B

Big Color

A confident consumer brand. Saturated color blocks, a bento grid of benefits and playful micro-interactions that make the offer feel friendly.

Feels like
A modern direct-to-consumer brand, bold and warm
Type
Bricolage Grotesque for headlines, Rubik for text
Signature
Bento tiles: a dose ladder that grows, a live coach chat, an “insurance required” switch that refuses to turn on
Effort
Medium. Best with new product renders.
Watch out
A real rebrand: the palette moves away from today’s navy
  • UI UX Pro Max: Bento Box Grid style, Startup Bold type
  • Frontend Design
  • CSS Animations
  • Make Interfaces Feel Better
  • Full build: Higgsfield or Bloom for 3D renders
Open prototype

Direction C

Six Months

A cinematic scroll story. You scroll through months one to six: the month counter and dose ring change, while the price stays pinned on screen and never moves.

Feels like
A product launch film. Dark, dramatic, memorable.
Type
Bebas Neue for display, Source Sans 3 for text
Signature
Pinned, scroll-driven journey with snap points and a fixed price bar
Effort
High. Motion needs testing on older phones.
Watch out
Strong as a campaign page; heavy as the whole site. Reduced-motion version included.
  • UI UX Pro Max: Parallax Storytelling, Bold Statement type, GSAP preset
  • GSAP ScrollTrigger
  • Frontend Design
  • Full build: GSAP Text, Web Animation Design, AnimatedWebs backgrounds
Open prototype

Direction D

Plan Builder

The home page is a tool. Pick a medication and your weight, and see your whole plan: dose steps, an illustrative goal path, delivery dates and the total cost.

Feels like
A fintech or health app. Clear, product-led, numbers first.
Type
Manrope, with tabular numbers
Signature
Live chart with a month scrubber, real delivery dates from today, running cost
Effort
Medium to high
Watch out
The goal path must never read as a promise; legal review of the wording
  • UI UX Pro Max: data dashboard style, chart guidance
  • Frontend Design
  • Full build: Dataviz, Interaction Design, A11y Enforcer

Recommendation

A (Itemized) as the main site, with D’s plan builder on the pricing page. Together they answer the two questions skeptical visitors have, “what does it really cost?” and “what will my plan look like?”, and both are cheap to keep accurate. Keep C for a campaign page if marketing wants something cinematic.

Version 1 (the current build, which keeps today’s look) is still at the site root. These prototypes are for review only and are not linked from the site.
