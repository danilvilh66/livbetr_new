# Livbetr website

The redesigned marketing site for Livbetr: GLP-1 weight-loss care, priced honestly.

Static HTML, CSS and vanilla JavaScript, generated by a small Node build script with no runtime dependencies. The built site is committed in `docs/`, so you can open it without installing anything. It runs on any static host (Netlify, Vercel, Cloudflare Pages, S3, GitHub Pages) and works from a sub-path, because every link is relative.

## Pages

| Path | What it does |
| --- | --- |
| `/` | Home: hero, the dose-and-price ladder, how it works, plans, 15% estimate, care team, reviews, FAQ, offer |
| `/how-it-works/` | The four steps, who does what (Livbetr, clinicians, pharmacies), what stays with you |
| `/pricing/` | Plans, the ladder, what is included, semaglutide vs tirzepatide table, billing FAQ |
| `/eligibility/` | Six-question eligibility check with BMI, safety screening and a plan suggestion that hands off to `intake.livbetr.com` |
| `/faq/` | 21 questions in 5 categories, live search with highlighting, category filters, deep links (`/faq/#cancel`) |
| `/contact/` | Who to contact for what, live "open now" status in Eastern Time, validated contact form |
| `/404.html` | Branded not-found page |

Legal documents (terms, privacy, refund policy and the rest) still link to the current pages on livbetr.com until legal approves new copy.

## Open it with VS Code Live Server

Open the repository folder in VS Code and click **Go Live**. `.vscode/settings.json` points Live Server at `docs/`, so the home page opens straight away.

If Live Server ignores the setting (for example in a multi-root workspace), right-click `docs/index.html` and choose **Open with Live Server**.

## Edit and rebuild

```bash
npm install
npm run dev        # builds docs/ and serves it at http://localhost:4173
npm test           # builds, then runs the Playwright and axe suites
```

`npm run icons` regenerates the favicons and the social share image from `public/favicon.svg`.

## Where things live

```
build.mjs                 renders src/pages/*.mjs into docs/, writes sitemap.xml and robots.txt
docs/                     the built site (generated: edit src/ and public/, then npm run build)
src/data.mjs              prices, phone, hours, FAQ, reviews, dose schedules: edit content here
src/layout.mjs            <head>, header, footer, image helper
src/components.mjs        dose ladder, plan cards, steps, estimate, reviews, FAQ, offer band
src/pages/*.mjs           one module per page
public/assets/css/main.css  design tokens and all styles
public/assets/js/main.js    all behaviour, progressive enhancement over working HTML
design-system/livbetr/      UI UX Pro Max design-system output (MASTER.md)
DESIGN.md                 the design decisions and the reasons for them
tests/                    Playwright end-to-end, accessibility (axe) and responsive tests
```

## Changing content

- **Prices or promo:** `site.promo` and `treatments[].price` in `src/data.mjs`. Set `promo.active` to `false` to remove the banner everywhere.
- **FAQ:** add an object to `faqs` in `src/data.mjs`. `home: true` also shows it on the home page.
- **Support hours:** `site.supportHours`. The contact page's open/closed badge reads these values.

## Quality checks

- 88 Playwright tests on desktop Chrome and a Pixel 7 profile: every page, every interactive feature, links, images, 404, sitemap.
- axe-core WCAG 2.2 AA scan on every page: 0 violations.
- Lighthouse (mobile): Performance 98 to 99, Accessibility 100, Best Practices 100, SEO 100.
- No third-party requests: fonts are self-hosted, no trackers.
